# Heizungsrechner

Kostenloser Vergleichsrechner für Heizsysteme – läuft komplett im Browser, ohne Server und ohne Datenübertragung.

**Live:** https://jackoneill199.github.io/heizungsrechner/

## Funktionen
- Vergleich von 9 Heizsystemen: Öl (Brennwert / Niedertemperatur), Gas, Wärmepumpe, Brennstoffzelle (mit/ohne Strom), Pellets, Wärmepumpe + Pellets, Direktstrom
- Kosten pro Monat/Jahr, Energieeinsatz und CO₂-Emissionen
- Investition, Förderung, Energiepreissteigerung und Gesamtkosten über 1–40 Jahre inkl. Amortisation
- Brennstoffzelle vs. Gastherme („Lohnt sich der Betrieb?“)
- Eingaben werden lokal gespeichert, Export/Import als JSON, teilbarer Link, Druck/PDF, Dark Mode

## Benutzung
`index.html` im Browser öffnen – fertig. Alle Werte (Preise, Wirkungsgrade, Investitionskosten …) sind Beispielwerte und lassen sich anpassen.

## Hinweis
Die Ergebnisse sind Näherungen ohne Gewähr und ersetzen keine Fachplanung. Investitionskosten und Förderquoten sind Platzhalter.
